BOXXY v126 SOLVER ADAPTER TEST REPORT
======================================

Package
-------
- Top-level release directory: BOXXY_v126
- Active cache identifiers: v126
- No legacy FESS solver or JavaScript solving fallback

Loader changes
--------------
- No direct cross-origin module import
- No Blob-module dynamic import
- Three mirrors begin concurrently rather than waiting sequentially
- Each mirror has a 15-second request limit
- Generated wasm-bindgen exports are converted to local worker bindings
- WASM magic bytes are checked before initialisation
- A one-push puzzle must solve before the engine is announced ready
- Full per-mirror failure details are returned to the BOXXY status panel

Static verification
-------------------
- JavaScript syntax: passed for boxxy.js, solver-worker.js and route verifier
- index.html references v126 assets
- solver worker reference and worker name use v126
- ZIP root folder is BOXXY_v126

Runtime limitation
------------------
The packaging environment cannot make browser-origin requests to the external
engine mirrors, so the external download and WASM execution could not be run
here. The worker performs its own engine self-test in the user's browser before
it begins a requested solve.
