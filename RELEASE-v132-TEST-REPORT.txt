BOXXY v132 TEST REPORT
======================

Static checks
- boxxy.js, data.js, solver-route-verifier.js, solver-worker.js and pack-builder.js passed Node syntax checks.
- All index cache identifiers use v132.
- No v131 identifiers remain in active root files.
- Archive root is BOXXY_v132.

Share-link checks
- A Unicode title and XSB layout round-tripped successfully through the URL-safe codec.
- The tested link format was:
  https://quornsam.github.io/Sokoban/#p=<URL-safe-code>
- The codec rejected a layout without matching boxes and goals.
- Decoded layouts are limited to 36 × 36 and checked for legal Sokoban symbols, exactly one player, at least one box, and equal box/goal counts.
- Static flow checks confirm that shared mode hides pack selection, level selection and Level Maker entry points.
- Static flow checks confirm that restart and the completion button reload the shared puzzle instead of loading a campaign level.

Solver-dialog check
- finishSolverRun now sets the progress element to 100, stopping its indeterminate animation after success, failure, cancellation or worker error.
- The progress area remains hidden in the initial idle state.

Environment limitation
- A full graphical browser navigation test was attempted, but this execution environment blocks browser navigation to local, file and intercepted test URLs. Runtime behaviour was therefore checked through codec execution, JavaScript syntax validation and source-flow assertions rather than a live navigated page.
