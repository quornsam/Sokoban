BOXXY v114 — PURE FESS SOLVER TEST REPORT
==========================================

Build scope
-----------
The v113 solver algorithm was removed and replaced from scratch.
The game UI, CSS, level data, artwork, audio and asset files were retained.
Only solver-core.js, solver-worker.js and solver-specific integration text/cache references were changed.

Engine
------
Solver-core version: 4.0.0
Reported strategy for every search: fess

The engine contains one Feature Space Search:
- one forward Sokoban domain-state graph;
- same-box macro moves;
- canonical player-reachability states;
- cyclic FESS feature cells;
- alternate focus on the strongest FESS cell;
- accumulated advisor weights of 0 or 1;
- a transposition table with lower-weight relaxation;
- dead-descendant propagation.

No reverse solver, A*, IDA*, bounded portfolio or secondary solver fallback remains in solver-core.js or solver-worker.js.

Structural rejection is limited to:
- static reverse-unreachable dead squares;
- solid 2 x 2 wall/box blocks containing an off-goal box;
- failure of a complete static box-to-goal matching;
- states whose full descendants have been exhausted and proved dead.
