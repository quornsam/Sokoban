BOXXY v137 TEST REPORT
=======================

Build base
----------
Full v135 legal/Pack Builder release with the v136 linked-solution synchronisation patch applied before the v137 work.

Save-position tests
-------------------
PASS  Save button is disabled at the untouched starting position when no checkpoint exists.
PASS  A legal move enables SAVE.
PASS  SAVE stores player, box positions, moves, pushes, facing, route and elapsed time in localStorage.
PASS  Immediately after saving, the control reads SAVED.
PASS  Restart returns the board to its authored starting position and changes the control to RESUME.
PASS  RESUME restores the exact saved player/box state and counters.
PASS  The restored checkpoint cannot be undone past the saved boundary.
PASS  Checkpoints are scoped by pack and level and rejected when the authored layout signature changes.
PASS  Completing a campaign level removes its checkpoint.
PASS  Level Maker test mode and shared-puzzle mode hide the checkpoint control.

Compatibility checks
--------------------
PASS  boxxy.js passed Node.js syntax validation.
PASS  pack-builder.js passed Node.js syntax validation.
PASS  Browser DOM test completed in headless Chromium using an isolated localStorage mock.
NOTE  Expected character-image loading warnings occurred in the isolated DOM test because filesystem/network asset loading is restricted in the test environment; they do not affect checkpoint logic.

Reverse-built custom puzzle
---------------------------
The separately supplied puzzle was generated by legal reverse pulls from the completed board.
68 of 135 boxes begin off-goal (50.4%).
The supplied 1,327-move / 69-push forward route was replayed programmatically and completes the board.
