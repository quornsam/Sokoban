BOXXY v131 RELEASE TEST REPORT
================================

SCOPE
-----
This release adds verified solution-string import to the Level Maker solver modal.
It is built from BOXXY v130 and leaves level data, assets, pack drafts and Daily
Puzzle data unchanged.

STATIC CHECKS
-------------
- All active page cache tags and solver-worker references use v131.
- JavaScript syntax checked with Node.js.
- The archive root is BOXXY_v131.
- No direct HTML download is supplied; release is packaged as one ZIP.

SOLUTION IMPORT BEHAVIOUR
-------------------------
- Accepts UDLR in either case, whitespace and arrow symbols.
- Independently replays the route against the current Level Maker board.
- Rejects invalid characters, wall collisions and illegal pushes.
- Distinguishes a legal but incomplete route from a solved route.
- APPLY IMPORT remains disabled until a route is verified against the current
  board.
- Editing either the puzzle or the imported string invalidates prior approval.
- Applied routes are normalised to lower-case walking moves and upper-case pushes.
- The attached route is then available to Level Maker test mode and the hidden
  five-click + S guided solve.

BROWSER TEST
------------
A local Chromium test opens the Level Maker and solver modal, imports a known
one-push solution, verifies it, applies it, and checks that an illegal route is
rejected without enabling Apply Import.
