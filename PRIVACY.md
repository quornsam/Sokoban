# BOXXY Privacy Information

Effective: 19 July 2026

BOXXY is a static browser game hosted through GitHub Pages.

## Information stored in your browser

BOXXY stores campaign progress, manually saved gameplay positions, settings, Level Maker saves, custom solutions, Level Pack drafts and Daily Puzzle drafts using browser local storage. This information is not intentionally sent to Sam Cornwell and is not committed to GitHub automatically.

Clearing browser site data may erase these records.

## Shared-puzzle links

A shared custom-puzzle link contains an encoded puzzle title and starting layout in the URL fragment. The link is unlisted, not encrypted. Anyone who receives it can decode and play the puzzle. URL fragments are normally handled by the browser rather than sent as part of the HTTP request, but copying or sharing the complete URL reveals the puzzle code.

## External solver requests

When you start the optional solver, BOXXY requests the Rust/WebAssembly solver files from third-party hosting locations, currently including jsDelivr, GitHub-hosted pages and GitHub raw-content services. Those providers may receive ordinary technical request information such as IP address, browser information and request time under their own privacy policies.

The puzzle being solved is processed in your browser after the solver files have loaded; BOXXY does not intentionally upload the puzzle to Sam Cornwell.

## GitHub Pages

GitHub may process ordinary hosting and security information when you visit a GitHub Pages site. GitHub's own terms and privacy statement apply to that hosting activity.

## Analytics and advertising

BOXXY v138 does not include first-party analytics, advertising trackers or user accounts.

## Contact

Privacy questions may be directed to Sam Cornwell through the `quornsam` GitHub profile.
