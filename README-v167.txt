BOXXY v167 — Rainbow Mode switch placement

Replace these three files in the repository root:
- index.html
- styles.css
- boxxy.js

The Rainbow Mode switch is now permanently visible inside the same horizontal bar as the target-colour controls.

OFF:
- The bar shows the Rainbow Mode switch and standard Sokoban notation.
- Colour swatches are hidden.
- Paste/export uses . $ * and the usual standard symbols.

ON:
- The same bar expands to show all 15 target-colour swatches.
- Coloured target and box-on-target letter codes are enabled.
