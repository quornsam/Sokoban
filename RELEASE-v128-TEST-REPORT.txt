BOXXY v128 RELEASE TEST REPORT
================================
Date: 18 July 2026

STATIC CHECKS
-------------
- boxxy.js passed Node.js syntax checking.
- solver-worker.js passed Node.js syntax checking.
- solver-route-verifier.js passed Node.js syntax checking.
- Active HTML cache identifiers and worker references use v128.
- The release root folder is BOXXY_v128.

HEADLESS CHROMIUM FUNCTION TESTS
--------------------------------
The real v128 HTML, CSS, level data, route verifier and boxxy.js were loaded in
a headless Chromium test harness. Asset fetch failures caused by the isolated
inline harness were ignored; gameplay logic and interface behaviour were run.

Passed:
- Saved levels display alphabetically, case-insensitively with numeric ordering.
- A 13 × 13 MAZE generation produced connected-looking internal structure,
  exactly one player, three boxes and three goals.
- Twenty consecutive unchecked maze generations completed with the requested
  box/goal counts and substantial internal walls.
- Five consecutive TESTED maze generations completed and supplied verified
  reverse-built solution paths.
- Manually completing an unsolved maker test automatically attached the exact
  recorded route as its guided solve.
- Saving and reloading that level restored the newly learned guided route.
- Blocked moves were not recorded.
- Undo removed the undone movement from the recorded solution route.
- The five character clicks + S guided-solve control replayed the maker puzzle's
  attached solution while remaining in maker-testing mode.
- The guided replay did not load or solve a campaign level.
- Completing a puzzle by a different route displayed APPLY SOLVE.
- APPLY SOLVE replaced the editor puzzle's attached route and returned to the
  Level Maker.
- A 390-pixel-wide layout smoke test found no horizontal page overflow.

SOLVER NETWORK LIMITATION
-------------------------
This test did not exercise the external Rust/WebAssembly network download. The
solver remains dependent on the upstream runtime sources documented in
CREDITS-AND-LICENCES.txt. All v128 changes described above work without that
external solver connection.
