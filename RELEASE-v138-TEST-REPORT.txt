BOXXY v138 TEST REPORT
=======================

----------

Requested changes
-----------------
PASS  Legal page includes a discreet BOXXY VERSION 138 label.
PASS  Pack entries can be renamed without renaming or unlinking the source Level Maker save.
PASS  Pack author is the default author for every puzzle.
PASS  Individual puzzle authors can be overridden or reset to inherit the pack author.
PASS  Custom puzzle names and authors survive linked layout/solution synchronisation.
PASS  Pack order grid can be set from 1 through 8 columns and the choice persists per draft.
PASS  Saved-library cards include direct EDIT and PLAY controls.
PASS  Ordered pack cards include direct DETAILS, EDIT and PLAY controls.
PASS  EDIT opens the linked saved puzzle in the Level Maker; if the source save is missing, the stored pack snapshot opens as an unsaved puzzle.
PASS  PLAY loads the selected puzzle directly into BOXXY and preserves its pack display name.
PASS  Solved library, pack and Daily cards display the number of moves in the attached verified route.
PASS  Pack script/JSON exports include per-level author and solutionMoves fields.
PASS  XSB exports include per-puzzle author and solution move comments.
