BOXXY v166 — optional Rainbow Mode

Update-only package. Upload the contents to the root of the existing BOXXY repository.

Changed files:
- index.html
- boxxy.js
- styles.css

Behaviour:
- Rainbow Mode is off by default for first-time users.
- Off uses standard Sokoban symbols: . target, $ box, * box on target, + player on target.
- On reveals the 15-colour target palette and colour-letter import/export codes.
- Switching off temporarily preserves current colour choices in memory, but standard saves, tests, share links and pack data omit colour metadata.
- Saved coloured levels automatically reopen in Rainbow Mode.
