Memory changes
--------------
- Dense desktop allowance increased from 180,000 states in v117 to 900,000 states on the high-memory tier.
- State arrays grow from an initial 90,000-state allocation instead of reserving the full allowance immediately.
- The global transposition table uses typed arrays and exact state comparison rather than retaining a JavaScript string for every visited position.
- In the 30-second Node.js Small Chessboards 38 diagnostic, v118 generated about 136,000 states while remaining near 260 MB RSS. The equivalent v117 diagnostic was about 327 MB RSS with its large preallocation benchmark.
- Reaching a configured allowance remains a clean stop. No frontier is silently discarded and no branch is pruned merely to save memory.
