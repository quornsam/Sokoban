BOXXY v136 — saved-solution / pack-draft synchronisation patch

Replace these files in the repository root:

- index.html
- boxxy.js
- pack-builder.js

What this fixes
---------------
1. A solution applied to the currently loaded saved level is now written to that saved-level record automatically, provided the editor board still exactly matches it.
2. Pack drafts and the Daily Puzzle queue refresh every linked entry from its source saved level.
3. Existing pack order is preserved. Only the level name, board snapshot, dimensions, box count and solution are refreshed.
4. Pack cards change immediately from UNSOLVED to SOLVED after a solution is attached and saved.
5. Reopening the Pack Builder also repairs stale linked entries created by earlier versions.

Unlinked/copied snapshots without a source saved-level ID remain independent and are not altered.
