What is Sokoban?

In a Sokoban puzzle, the player moves through a small arrangement of floors and walls and pushes boxes onto marked target squares. A box can normally be pushed only when there is free space beyond it. Because boxes cannot simply be pulled back out, one careless push can make a puzzle impossible.

Simple rules, difficult consequences.

The challenge is not just finding a route for the player. It is deciding where each box must travel, in which order, while preserving the space needed to stand behind it for later pushes.

Think before pushing

Walking is usually reversible. A push often is not. Good Sokoban play treats each push as the important decision.

Avoid deadlocks

A box pushed into a non-target corner is the classic example, but walls and groups of boxes can create less obvious dead positions too.

Work from the targets

It can help to imagine the final push onto each target and ask where the player and box would have to be immediately beforehand.

Use undo to learn

Experimentation is part of solving. BOXXY includes undo and restart so you can test an idea without losing the puzzle entirely.
